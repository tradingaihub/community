# TradingAIHub Community

Discussions for [TradingAIHub](https://tradingaihub.com), the independent, weekly-checked directory of AI tools for finance and trading: MCP servers, agent skills and market-data APIs.

Comments on the [TradingAIHub blog](https://tradingaihub.com/blog/) live here too. Each article has its own thread in **Articles**, created by [giscus](https://giscus.app) the first time someone comments on the article page.

## Categories

| Category | Use it for |
|---|---|
| **Articles** | One thread per blog article (comments from tradingaihub.com/blog). New threads are created by the site, not by hand. |
| **Tools & Platforms** | Experiences, setup questions and comparisons for specific MCP servers, agent skills and APIs. |
| **Ideas & Requests** | Tools we should list, features for the site, the API or the MCP server. |
| **Q&A** | Questions with an answer you can mark as accepted. |

Found a listing that is wrong or out of date? Open an issue in [tradingaihub/tradingaihub](https://github.com/tradingaihub/tradingaihub/issues) or email hello@tradingaihub.com. To submit a tool, use [tradingaihub.com/submit](https://tradingaihub.com/submit/).

## Ground rules

- Be kind and specific. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
- **Not investment advice.** No trade calls, price predictions, signals or "which coin should I buy" threads. Talk about tools, not tickers.
- **No spam or undisclosed promotion.** If you build or are paid by a tool you mention, say so. Referral and affiliate links are removed.
- **Never post secrets.** No API keys, account numbers, wallet seeds or screenshots that show balances.
- Security problems in a listed tool: report them privately to its maintainers, or to hello@tradingaihub.com, not in a public thread.

Moderators may edit, hide, lock or delete posts that break these rules.
